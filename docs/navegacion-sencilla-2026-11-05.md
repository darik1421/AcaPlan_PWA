# Navegación y textos breves

Primera mejora de facilidad de uso: menú agrupado en Planificación, Horarios y Configuración, con las mismas opciones y permisos. Entrada inicial por capacidades: generación para Director/Administrador, borradores para director departamental, entrega para coordinador y horario personal para docente. Una elección explícita de pantalla se conserva.

Se acortaron las indicaciones repetidas de entrega, importación y restricciones. En esta primera pasada los ajustes se plegaron; la revisión visual posterior recuperó sus tarjetas visibles a petición del usuario. «Conservar días de este borrador» solo se habilita al seleccionar un borrador existente. No cambian las reglas, el algoritmo, las plantillas, las RPC ni los datos. La consulta incompleta de borradores informa un error y permite reintentar sin romper la pantalla.

Pruebas: navegación inicial por perfil, agrupación y acceso a todas las opciones autorizadas, cambios de permisos, invalidación del diagnóstico y controles del generador. Comprobación visual aislada en navegador para Director, coordinador, director departamental y docente; sin conexión a Supabase ni nuevas cuentas reales. Se conserva el diseño institucional existente. Esto es una primera pasada; no declara revisados todos los formularios o estados de la aplicación.
